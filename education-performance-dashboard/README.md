# Educational Performance & Resource Allocation Dashboard

## 📊 Project Overview
This Power BI dashboard analyzes student academic performance, attendance trends, study habits, and resource allocation insights.

## 🚀 Features
- KPI Cards
- Department-wise Performance Analysis
- Attendance vs Final Score Analysis
- Grade Distribution
- At-Risk Student Identification
- Interactive Slicers

## 🛠 Tools Used
- Power BI
- DAX
- Data Visualization
- CSV Dataset

## 📈 Insights
- Higher attendance improves academic performance
- Some departments require additional support
- Study hours correlate with better scores
