# Human Resources Analytics Dashboard

## Project Overview
This Power BI dashboard analyzes employee attrition, workforce performance, salary trends, and hiring insights.

## Features
- Employee Attrition Analysis
- Department-wise Insights
- Salary Analysis
- Job Satisfaction Metrics
- Hiring Forecasting
- Interactive Filters

## Tools Used
- Power BI
- DAX
- CSV Dataset
